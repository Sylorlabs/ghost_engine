# MUL-Free with max_len=24 (Remove 12-Cap) — Exp5 (2026-05-23)

## What the experiment asked

Exp2/Exp3 (MUL-free meta-engine and MUL-free + LMG) both plateau at a strong
attractor near −215 composite quality, using `MAX_LEN_RAND=11, MAX_LEN_MUTATE=12`.
The experiment asks: is the −215 floor a **fundamental limit of MUL-free mixing**,
or is it an **artifact of the 12-instruction program-length cap**?

Exp5 doubles the program-length budget (`MAX_LEN_RAND=23, MAX_LEN_MUTATE=24`)
and runs the same 3-tier meta-engine over the same MUL-free opset, looking
for whether the extended search space allows escape from the −215 attractor.

**Hypothesis:** if −215 is a cap artifact, some seeds should escape it with
longer programs. If −215 is fundamental, all seeds remain stuck regardless.

## Findings and interpretation

**Result: L24 escape is real but produces bad RNGs. MUL-necessity conjecture confirmed via a new path.**

1. **−215 floor is a cap artifact, not a fundamental limit:** seeds DEAD and
   1111 both escaped (to −163.47 and −162.11 respectively). With 24 instructions,
   the MUL-free fitness landscape has better-quality basins unreachable with
   max_len=12. **2/3 seeds find these basins**; both via late-epoch discoveries.

2. **The escape is reproducible but program-family-dependent:** both escapes
   converge to the same attractor (≈-162 to -163) via different program families.
   DEAD's escape produces ADD-dominant programs; 1111's escape produces
   XOR-dominant programs. The attractor is a quality level, not a specific program.

3. **Better internal fitness, worse RNG — failure mode varies by program family:**
   the escaped champions each achieve internal fitness −162 vs −215 (24%
   improvement). But both fail PractRand via different mechanisms: DEAD fails
   mod3n (modular bias from ADD) while 1111 fails BRank (GF(2)-linear from XOR).
   The internal fitness metric improves while actual RNG quality stays bad.

4. **MUL-necessity confirmed via length axis:** even with 24-instruction MUL-free
   programs, the discovered mixers fail PractRand catastrophically. The escape
   from −215 is a fitness-metric escape, not a quality escape. A real
   high-quality mixer still requires MUL/MUM.

5. **Op-family determines failure mode:** ADD-dominant programs (seed DEAD) fail
   mod3n — the residue-class tests detect modular structure that ADD preserves and
   MUL destroys. XOR-dominant programs (seed 1111) fail BRank — the binary rank test
   detects GF(2)-linear structure from XOR/ROTL/SHL families. Both paths fail, via
   the specific weakness of their dominant op class. MUL/MUM break both.
